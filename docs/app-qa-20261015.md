# 보고가고 앱 전체 점검 (2026-10-15, 실기기 SM-G960N · 테스트 계정 민우)

점검 범위: 홈(날씨·알림·유튜브·앨범/사진·다가오는 여행), 탐색(지도), 저장(유튜브 저장), 마이(지난/예정 여행·내 일정·편한 모드),
여행 만들기 1~4단계 → **실제 AI 일정 생성 1회**(강릉 1박 2일, 82초), 서버 로그.
오류(500·크래시)는 없었다. 아래는 보완점이다.

## A. 사용자에게 바로 보이는 문제 (우선)

| # | 화면 | 현상 | 제안 |
|---|---|---|---|
| A1 | 홈 · 다가오는 여행 | 여행 이름이 첫 장소로 나옴: "정동진 해변 여행"(실제 "강릉 여행") | 여행 제목/여행지로 표시 |
| A2 | 저장 → 유튜브 영상 상세 | 열 때 추천 여행지를 EXAONE으로 고르느라 **약 50초** 대기 (로그 49.7초) | 결과 캐시 + 먼저 화면을 띄우고 추천은 나중에 채우기 |
| A3 | AI 일정 품질 | 저녁 식사로 **술집**("안목해변술집 문문")이 반복 선택됨 | 식사 후보에서 주점·술집 제외 |
| A4 | AI 일정 품질 | 1일차 15:00~17:30 **빈 시간 2.5시간**, 관광 150분으로 적음(경고 표시됨) | 빈 시간이 길면 근처 장소·휴식 보충 |
| A5 | AI 일정 품질 | 2일차 저녁 식당이 마지막 장소에서 **12km(29분)** 떨어짐("더 가까운 후보 없음"으로 유지) | 식사 후보 검색 반경을 그날 동선 기준으로 |
| A6 | AI 일정 품질 | 이틀에 카페 3곳(휴식 카페 포함) | 카페 취향이어도 하루 1곳 정도로 제한 |

- A1 홈·일정 화면 여행 이름 → 여행 제목/여행지("강릉 여행") — 실기기 확인
